# Security policy

## Supported versions

Only the latest release receives security fixes. Upgrade before reporting an issue found on an older version.

## Reporting a vulnerability

Do not open a public issue. Report it privately through GitHub: the repository's **Security** tab, then
**Report a vulnerability**.

Include the affected version (`beaver version`), the component (SMTP, IMAP, HTTP API, admin UI, antispam plugin), steps
to reproduce and the impact you expect. We acknowledge reports within 7 days and agree a disclosure date with you once
a fix is ready.
